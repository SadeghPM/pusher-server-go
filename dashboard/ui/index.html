Three steps

From zero to broadcasting.

Install the binary, point Laravel at it, and open the control room. That is the whole setup.

01

Install the server

Use the installer or drop a release binary on any host. A single process serves WebSockets and the REST API.

02

Point Laravel at it

Set the Pusher environment keys to your host and port. Your existing broadcast events stay exactly as they are.

03

Open the control room

Log in with the admin_token from your config, watch events arrive, and fire a test broadcast.

terminal 
# Linux installer, creates a systemd service
curl -sSL https://raw.githubusercontent.com/SadeghPM/pusher-server-go/main/install.sh | sudo bash

# or run a release binary directly
./pusher-clone --config ./config.yaml

The installer writes /opt/pusher-clone/config.yaml and registers a service. Manual installs are fully supported too.

.env 
BROADCAST_CONNECTION=pusher

PUSHER_APP_ID=my-app-id
PUSHER_APP_KEY=my-app-key
PUSHER_APP_SECRET=my-app-secret
PUSHER_HOST=127.0.0.1
PUSHER_PORT=6001
PUSHER_SCHEME=http
PUSHER_APP_CLUSTER=mt1

Match these to a tenant in config.yaml. In production, use HTTPS and set PUSHER_SCHEME=https.

Laravel + Echo 
// Laravel — dispatch an event
broadcast(new OrderShipped($order))->toOthers();

// Browser — listen with Echo
Echo.private(`orders.${orderId}`)
    .listen('OrderShipped', (e) => {
        console.log(e.order);
    });

Nothing else changes. The server handles channels, presence, auth and delivery in memory.
